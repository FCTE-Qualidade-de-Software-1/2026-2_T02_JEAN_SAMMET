# Critérios de Aceite: 0 - Premissas Iniciais

| ID | Critério | O que fazer para ser excelente | Feito? |
| :--- | :--- | :--- | :---: |
| P1 | Seleção das características de qualidade | Escolher 3 a 4 características, indicar a norma SQuaRE e justificar. Ao concluir, discutir as relações entre elas, com evidências, limitações e os casos sem dados suficientes. | **Parcial** |
| P2 | Definição das métricas (GQM) | Ligar objetivos, questões e métricas. Para cada métrica, documentar definição, cálculo, fonte dos dados, coleta e critérios de interpretação. | **Não** |
| P3 | Gestão do projeto (PSM/CID) | Medir desempenho dos processos, calendário e progresso, e recursos e custos. Registrar as medições, a interpretação e as decisões de gestão. | **Não** |
| P4 | Repositório do projeto | Usar o Git da disciplina durante todo o desenvolvimento, com documentos, dados, gravações e atas de reunião. | **Parcial** |
| P5 | Rastreabilidade dos dados | Disponibilizar dados de coleta, consolidação e os procedimentos de tratamento, permitindo conferir a origem dos resultados. Proteger a identificação dos participantes. | **Não** |
| P6 | Registro de entrevistas | Gravar as entrevistas com o consentimento dos participantes, quando houver. | **Não** |
| P7 | Formato do artigo | Escrever em LaTeX com modelo da SBC, ACM ou IEEE, preservando a formatação do modelo. | **Não** |
| P8 | Conteúdo do artigo | Reunir o necessário para entender o problema, os objetivos, a metodologia, a avaliação e os resultados. | **Não** |
| P9 | Limite de páginas | No máximo 15 páginas, incluindo referências, apêndices e anexos do PDF. Acima disso, o artigo é rejeitado. | **Não** |
| P10 | Submissão | Entregar tudo no Moodle em PDF. A entrega de conclusão traz o artigo e identifica o repositório e a versão. | **Não** |
| P11 | Processo de avaliação de produto | Seguir o processo de avaliação da SQuaRE (recomendado). | **Parcial** |
| P12 | Link do repositório no artigo | Incluir no artigo o link direto para o repositório da equipe. | **Parcial** |
| P13 | Tabela de contribuição | Incluir a tabela de contribuição dos membros como apêndice do artigo. | **Não** |
| E1-1 | Entrega 1: GitPage | Página atualizada com todo o trabalho até a Fase 2. | **Parcial** |
| E1-2 | Entrega 1: artigo | Primeira versão com Introdução, Referencial teórico, Metodologia, Fase 1 e Fase 2. | **Não** |
| E1-3 | Entrega 1: tabela de contribuição | Tabela de contribuição da equipe. | **Não** |
| E1-4 | Entrega 1: release | Release E1, conforme data e hora definidas no Moodle. | **Não** |

**Ponto a esclarecer com a professora:** P9 inclui apêndices no limite de 15 páginas, enquanto P13 diz que a tabela de contribuição, apêndice do artigo, não conta no limite.
